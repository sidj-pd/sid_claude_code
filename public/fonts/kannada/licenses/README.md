# Kannada fonts — licences

This repository is **public**. Every font file in `public/fonts/kannada/` is
redistributable; the licence texts that shipped with each family are in this
folder. Where a family shipped without a separate text, its licence is embedded
in the font's own `name` table (OFL §3 allows that).
